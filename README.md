# taskManagementSystem
### About
Task Management System is a full-stack web application that allows users to:
- Register and log in securely.
- Create and manage projects
- Assign and edit project details.
- Add and manage tasks within each project.

### Tech Stack
- Frontend: React + Vite
- Backend:	Node , Express
- Database	MongoDb

### Installation
git clone ```<repo-url>```<br>

#### Commands 
- client
```
cd client
npm install
npm run dev
```
- server
```
cd server
npm install
npm run start
```

### Environment Setup
Configure environment variables by following the .env.example file inside both client and server directories.

### Features
- User Authentication (Register & Login).
- Create up to 4 Projects per user.
- Edit, Delete, and View Projects.
- Create, Edit, Delete, and View Tasks.
- Assign Tasks to Other Users.
- Mark Tasks as Completed.
